scrcpy LAN v0.6.3：修复退出后后台进程残留。

主要更新：

- 关闭 GUI 时取消后台操作、停止全部投屏 / 音频会话，等待设备媒体静音和亮屏恢复完成，再关闭所用的 ADB 服务，避免后台任务在退出期间重新启动 adb。
- Windows 使用进程组管理本程序及其子进程。程序正常退出或被强制结束后，自动回收本程序启动的 scrcpy、adb 及后台后代进程，包括脱离父命令常驻的 ADB 服务。
- 初始化进程清理失败时不启动后台任务；UI 运行出错也会执行正常退出清理。

下载 Windows 10 / 11 x64 便携 ZIP，**完整解压**后运行 `scrcpy-lan.exe`。附带官方 scrcpy v5.0、adb、说明和许可证，同名 `.sha256` 用于校验下载。

验证：本地回归测试、vet、CGO_ENABLED=0 编译、官方 runtime SHA-256 校验与便携打包通过；默认 / 最小布局及 Windows 原生窗口检查通过。实际便携程序扫描中关闭、正常退出和强制结束后均无相关 GUI / scrcpy / adb 进程残留。三星已授权真机的音视频与 RAW 仅音频退出后均确认物理亮屏、媒体音量为 0。进程树回归覆盖 detached 后代及无关进程隔离。发布包来自此次提交的 GitHub Actions 构建，ZIP 与 `.sha256` 核对一致。

关闭 GUI 会关闭所用的 ADB 服务，共用该服务的其他工具会断开，重新执行 ADB 命令即可启动服务。强制结束无法保证完成手机静音 / 亮屏操作，也不会保证关闭启动前已存在的 ADB 服务。
