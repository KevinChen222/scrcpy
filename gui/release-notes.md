scrcpy LAN v0.4.0：结束投屏自动亮屏、四种音频编码、自定义缓存和按需实时日志。

主要更新：

- 勾选「启动后熄灭设备屏幕」后，停止投屏、关闭投屏窗口、异常退出或关闭 GUI 都会请求重新亮屏。检查物理显示状态，必要时重新应用休眠 / 唤醒；可能回到手机锁屏，断线时报告恢复失败。
- 纯音频模式新增 Opus、AAC、FLAC、RAW 选择，默认 Opus。FLAC 为无损压缩，RAW 为未压缩 PCM；选择这两项自动隐藏并忽略码率输入。
- Opus / AAC 自定义码率范围提高到 6–9000 Kbps。该范围是请求值，实际码率受设备编码器限制；高请求值不等于更高音质，音质优先推荐 FLAC。
- 所有连接方式、内容模式和档位支持关闭缓存、0.5 / 1 / 2 秒预设（默认 2 秒）及自定义 0–60 秒，支持三位小数。输入单位为秒，分辨率、帧率和码率输入均标明单位。
- 新增独立实时日志窗口，显示 GUI、ADB、scrcpy 信息与错误。仅打开时收集，关闭即停止并清空；不写日志文件，内存保留最近 64 KiB，配对码隐藏。
- 包含此前尚未发布的 USB 有线模式与 120 fps 高规格、自定义视频档位、UHID 手机输入法支持、全屏 / Esc 控制、紧凑并排布局和独立滚动设备栏。
- 精简 AI 更新指南；GUI 继续独立于上游投屏核心，正常上游更新可直接合并。便携包使用已校验的官方 scrcpy v5.0，未修改其运行文件。

下载 Windows 10 / 11 x64 便携 ZIP，**完整解压**后运行 `scrcpy-lan.exe`，无需额外安装 adb、scrcpy 或 Go。同名 `.sha256` 用于校验下载。无线模式需要已授权的无线调试，有线模式需要已授权的 USB 调试。

验证：自动化回归测试和 Go 静态检查；默认、最小及音频布局检查；真实 Windows 日志窗口启停 / 清空验证；三星 SM-S926U / Android 16 上八项短时检查，覆盖视频停止、GUI 退出、进程异常退出的物理显示 OFF → ON，以及 Opus / AAC / FLAC / RAW 音频初始化与退出亮屏。9000 Kbps Opus 请求可启动，但未测实际输出码率。短时检查不代表长时间听感、音画同步或 USB 120 fps 能力；解锁后的中文输入仍需本地实测。
