scrcpy LAN v0.6.1：新增应用图标。

主要更新：

- 从提供的设计图提取绿色叠放手机图案与白色圆角底板，去除外围背景和水印，作为后续 GUI 的应用图标。
- EXE 文件、主窗口、日志窗口和投屏外层窗口共用新图标；图标直接嵌入 EXE，完整解压后无需额外配置。
- ICO 包含 16、24、32、48、64、128、256 px 七种尺寸；本地与 GitHub Actions 均从同一 ICO 生成 Windows 图标资源。

下载 Windows 10 / 11 x64 便携 ZIP，**完整解压**后运行 `scrcpy-lan.exe`。附带官方 scrcpy v5.0、adb、说明和许可证，同名 `.sha256` 用于校验下载。

验证：本地测试、vet、CGO_ENABLED=0 编译、官方 runtime SHA-256 校验与便携打包；Windows 原生窗口启动及图标资源检查。发布包使用本次提交的 GitHub Actions 构建产物，并核对 ZIP SHA-256。

本次仅更新图标和构建资源；手机投屏、音频和多设备功能未重新进行实体设备实测。
