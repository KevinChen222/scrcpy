scrcpy LAN v0.6.2：修复重复设备与手机名称显示。

主要更新：

- 设备列表以手机为单位显示，优先使用手机设置中的设备名称；读取为空、null 或失败时保留型号 / 发现名称，仍可连接。查询在后台运行，名称与身份在本次运行中缓存。
- 保留 IP:端口与 mDNS 服务名等连接别名，修复合并覆盖标识造成的重复卡片；多个无线端口通过手机返回的序列号确认身份后合并。同型号、同名手机保持独立，身份无法确认时暂时保留多条。
- 手机卡片优先使用正在运行的连接，其次选择已连接的无线调试连接，再选择其他有效连接。配对端口继续独立显示，不用于投屏。
- 选中状态与会话按手机身份关联；刷新或地址变化后保持关联，不通过另一连接重复启动同一手机。已运行进程继续使用原 ADB 连接标识。

下载 Windows 10 / 11 x64 便携 ZIP，**完整解压**后运行 `scrcpy-lan.exe`。附带官方 scrcpy v5.0、adb、说明和许可证，同名 `.sha256` 用于校验下载。

验证：本地回归测试、vet、CGO_ENABLED=0 编译、官方 runtime SHA-256 校验与便携打包；默认 / 最小布局和 Windows 原生窗口检查。两台已授权真机的三个 ADB 连接合并为两张手机卡片，三星显示实际设置名称；真机视频解码、运行中刷新、防重复启动与单独停止通过。发布包使用本次提交的 GitHub Actions 构建产物，并核对 ZIP SHA-256。

两台同型号手机及名称读取失败场景通过回归测试验证，未用对应实体设备场景复测；厂商不提供标准设备名称或序列号时会使用备用名称或暂时保留多条。
