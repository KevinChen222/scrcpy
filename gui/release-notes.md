scrcpy LAN v0.6.0：多设备独立连接、全屏手动选区、默认结束后静音。

主要更新：

- 可同时运行多台设备，每台分别选择仅音频或画面和声音，使用独立档位、缓存和熄屏设置。左侧显示运行会话，支持单独停止和停止全部；异常退出不影响其他设备。
- 去掉自适应黑边识别和定期截图。F11 全屏后，按 Alt+Z →「选择显示区域（仅全屏）」，鼠标拖选并松开确认，等比例放大。可重选、取消或重置，选区保留到会话结束，解码尺寸变化后重置。
- 保留原生 scrcpy 的鼠标坐标映射，支持偏离画面中心的选区；每个投屏窗口独立管理全屏、缩放与快捷键。
- 「结束后静音设备媒体声音」默认开启。停止、关闭窗口、异常退出或关闭 GUI 后，将该设备媒体音量设为 0 并读取验证；可在启动前关闭该选项，音量可用手机音量键调回。
- 保留官方 scrcpy v5.0、UHID、熄屏结束恢复亮屏、四种音频编码和按需日志。

下载 Windows 10 / 11 x64 便携 ZIP，**完整解压**后运行 `scrcpy-lan.exe`，无需额外安装 adb、scrcpy 或 Go。同名 `.sha256` 用于校验下载。无线模式需要已授权的无线调试，有线模式需要已授权的 USB 调试。

验证：Go 回归测试覆盖多会话进程清理、独立播放设置、单独停止 / 全部停止、默认静音与取消静音、不居中选区和窗口调整后的坐标换算。三星 SM-S926U 上通过真实解码、普通 / 全屏启动、关闭 / 2 秒 / 3 秒缓存、前台 F11 / Esc、真实鼠标拖选、取消重选与重置，以及三种缩放几何检查；视频与四种音频模式结束后实测亮屏及媒体音量为 0。

本地构建：测试、vet、CGO_ENABLED=0 编译、官方 runtime SHA-256 校验与 ZIP 打包通过；默认 / 最小 / 多会话布局和真实 Windows GUI 的启动、缩放、最小化、最大化、全屏与还原检查通过。

验证边界：本机只连接一台实体手机，多台实体设备同时播放和具体播放器中的长时间观看、实际触控仍需本地实测。选区不会跨会话保存。
