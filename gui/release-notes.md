scrcpy LAN v0.8.0：升级 mygo 至 v0.10.0，全面重新设计原生中文界面并加入顺滑微动效。

主要更新：

- 两平台 mygo 从 v0.4.6 升级到 v0.10.0（Go 1.27.3+），保持 CGO_ENABLED=0、原生 GPU 渲染与完整便携包，不引入浏览器、自动更新或 mygo 音频播放。
- 全面重新设计主界面、配对弹窗与实时日志窗口：采用清新的翡翠绿工作台视觉层级、独立阴影卡片、内联高 DPI SVG 图标，以及顶部一键浅色 / 深色外观切换（默认浅色）。
- 加入克制且顺滑的 mygo 原生微动效：连接模式与音视频模式的弹簧滑块分段控件（`Match` + `Snappy`）、设置项弹簧滑动开关、设备/档位悬停微抬与 Oklab 色彩过渡、运行中设备与日志的实时脉动绿点、扫描中旋转刷新图标与加载指示器、设备计数数字滚动过渡、底部状态栏文字渐变形，以及弹窗弹簧缩放与二维码 2 分钟实时倒计时进度条。
- 工程与体验修复：在 `gui/go.mod` 添加 `ignore ./build`，修复 `go mod tidy` 与 `./...` 扫描构建目录导致失败的问题；主界面与实时日志窗口改为事件驱动 `Invalidate` 刷新，空载零轮询开销；手动连接与配对码输入支持回车提交；日志窗口新增内存占用显示、一键复制（带提示）与清空按钮；修复配对弹窗切换标签时缺少激活高亮以及会话结束后残留旧错误提示的问题。
- 官方 scrcpy v5.0.1 运行包及校验值不变，音视频仍由官方 scrcpy 处理；保留多设备、二维码配对、实时日志、三种缩放、全屏选区与 Linux 高 DPI / 启动超时修复。

下载与使用：

- Windows：`scrcpy-lan-v0.8.0-windows-x64.zip` 与 `.sha256`，完整解压后运行 `scrcpy-lan.exe`。
- Linux：`scrcpy-lan-v0.8.0-linux-x64.tar.gz` 与 `.sha256`，解压后运行 `./start.sh`。需要 GTK 3、OpenGL、Cairo、X11 / XWayland 和 GNU coreutils 的 `stdbuf`。

两个包均附带官方 scrcpy、adb、说明和许可证，保留整个 `runtime` 目录。发布以同一提交的 Windows / Linux CI 成功为前提，资产使用该次 CI 产物及 SHA-256，不上传本地构建包。

验证：Linux 本地测试、vet、Windows 交叉 `go vet` / 测试编译、便携构建与 SHA-256 检查通过；本地便携启动器 `gui/launch-linux.sh` 在真实 X11 桌面启动并经 SIGTERM 正常退出；真实 GTK 窗口二维码渲染（`TestLinuxQRNative`）及无头界面测试（默认、紧凑 1080×760 / 1536×790、最小 840×600、浅色 / 深色切换与动画收敛、多设备、仅音频与配对弹窗）全部通过。100% / 200% 缩放 X11 模拟投屏原生窗口回归由同提交 Linux CI 完成。

验证边界：本次未连接授权真机，未重新验证真实音视频、扫码配对、UHID、熄屏 / 亮屏和结束后静音；不把模拟窗口或截图当作真机成功。Windows 桌面实操与真机验证未在本机执行，Windows 包由 CI 测试、vet、构建和校验运行包，未进行代码签名。

二维码要求 Android 11+、同一 Wi-Fi 及可用 mDNS；网络受限时可使用配对码与手动连接。Windows 退出关闭所用 ADB 服务，Linux 保留共享服务；强制结束不能保证完成手机静音或亮屏清理。
