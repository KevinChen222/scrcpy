scrcpy LAN v0.5.0：投屏中即时切换缩放模式，自动识别比例与视频黑边。

主要更新：

- 投屏窗口新增「画面缩放」菜单，可随时切换保持比例、自适应（识别黑边）、裁剪铺满、拉伸铺满，无需重启。全屏时按 Alt+Z 打开菜单，菜单不占用全屏画面。
- 自适应通过已授权 ADB 在内存识别手机画面的黑边，等比例放大有效区域；允许少量手势条等边缘浮层，连续两次识别一致后更新。全黑场景保留上次结果，不保存截图。
- 自动使用实际解码尺寸与当前投屏窗口尺寸计算比例，适应横竖屏和窗口调整。裁剪铺满可进一步占满屏幕，但会裁掉边缘；拉伸铺满可能改变比例。
- 原生投屏窗口嵌入未修改的官方 scrcpy v5.0，保留视频解码、声音、UHID 与手机控制。F11 / Alt+F 切换全屏，Esc 优先关闭菜单或退出全屏，Alt+Q 关闭投屏。

下载 Windows 10 / 11 x64 便携 ZIP，**完整解压**后运行 `scrcpy-lan.exe`，无需额外安装 adb、scrcpy 或 Go。同名 `.sha256` 用于校验下载。无线模式需要已授权的无线调试，有线模式需要已授权的 USB 调试。

验证：Go 回归测试和 vet 通过，便携包已使用 CGO_ENABLED=0 构建并校验官方 runtime；默认 / 最小布局与真实 Windows 启动、缩放、全屏和退出检查通过。测试覆盖缩放选择、嵌套黑边和边缘浮层、横竖屏尺寸、窗口调整、输入坐标换算与既有会话清理。三星 SM-S926U / Android 16 上验证真实解码、普通 / 全屏启动、关闭 / 2 秒 / 3 秒缓存、四种模式的原生子窗口几何及 ADB 黑边截帧。一次前台 F11 / Esc 往返检查通过；完整前台复测受 PixPin 截图浮层阻挡，后续三组检查通过窗口消息验证全屏切换。

自适应约每 3 秒截帧，会增加 ADB 传输和手机截帧开销。较大的播放器控件、字幕、非黑背景或受保护内容可能限制识别；边缘小浮层可能一起被裁掉，可选保持比例或手动裁剪铺满。具体播放器与长时间观看效果、触控实操仍需本地实测。
